Votre projet ou Tailspin Toys, les skills de Matt Pocock, puis partager son écran

En ligne jusqu'au vendredi 23 octobre 2026. Retour à la page du livret.

Vous avez un projet sur lequel avancer aujourd'hui, un projet perso ou un projet client accessible depuis ce poste ? Restez dessus : passez directement à la partie 4, les skills. Sinon, installez Tailspin Toys, le projet d'entraînement de la journée : parties 1 à 4.

1. Vérifier ce qui est déjà là

Bash
git --version
node --version

Il faut git, et Node 24 (ou Node 22, à partir de 22.13). Évitez les versions impaires, 23 et 25 : Vitest ne les prend pas en charge. Ce qui répond n'est pas à réinstaller.

2. Installer ce qui manque

Windows, avec les droits d'administrateur

Dans PowerShell :

PowerShell
winget install --id Git.Git -e --source winget
winget install --id OpenJS.NodeJS.LTS -e --source winget

Puis fermez et rouvrez le terminal.

Windows, sans droits d'administrateur

  • Node : sur nodejs.org, téléchargez Node 24 LTS pour Windows au format .zip, et décompressez-le dans votre dossier personnel.
  • Git : sur git-scm.com, prenez la version Portable (64 bits), une archive qui s'extrait d'elle-même, et extrayez-la dans votre dossier personnel.

Puis, dans PowerShell, en remplaçant 24.X.Y par la version téléchargée :

PowerShell
$env:Path = "$HOME\node-v24.X.Y-win-x64;$HOME\PortableGit\cmd;$env:Path"

Ce réglage vaut pour ce terminal. Pour le garder : menu Démarrer, « Modifier les variables d'environnement pour votre compte », ligne Path, puis ajoutez ces deux dossiers.

Linux

Git, s'il manque (sans sudo, il est en général déjà là) :

Bash
sudo apt install git      # Debian, Ubuntu
sudo dnf install git      # Fedora

Node 24, avec nvm, sans sudo. Le paquet nodejs des distributions est souvent trop ancien.

Bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash

Fermez et rouvrez le terminal, puis :

Bash
nvm install 24

3. Installer Tailspin Toys, si vous n'avez pas de projet

Bash
git clone https://github.com/denneulin/tailspin-toys.git
cd tailspin-toys
npm ci
npm run dev

Ouvrez l'URL affichée, en général http://localhost:4321 : le catalogue de 21 jeux s'affiche. npm ci télécharge environ 90 Mo : à neuf sur le même wifi, comptez quelques minutes. Les tests tournent en moins d'une seconde :

Bash
npm run test:unit

Si ça coince

  • PowerShell refuse de lancer npm (« l'exécution de scripts est désactivée sur ce système ») : tapez une fois Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, ou passez par Git Bash.
  • npm ci échoue sur la version de Node : vérifiez node --version (24, ou 22 à partir de 22.13).
  • Le port 4321 est pris : le serveur prend le suivant, 4322 ; l'URL affichée fait foi.

4. Installer les skills de Matt Pocock

Lancez Claude Code dans votre projet, ou dans le dossier tailspin-toys (claude), acceptez le dialogue de confiance, puis :

Texte
/plugin marketplace add mattpocock/skills
/plugin install mattpocock-skills@mattpocock
  • Une seule voie, celle-ci : n'installez pas aussi la version de la marketplace officielle, chaque skill serait en double. Quand la portée vous est demandée, l'installation pour vous suffit.
  • Vérifiez avec /plugin : mattpocock-skills apparaît. Si /grill-with-docs n'est pas proposé quand vous tapez /grill, relancez Claude Code.
  • Le setup de Pocock est déjà fait dans Tailspin. Sur votre projet perso ou client : /setup-matt-pocock-skills, sur une branche, en choisissant les fichiers Markdown locaux.

5. Partager son écran, à la restitution

L'animateur dit laquelle des deux façons on utilise.

Sur la TV de la salle

  • Par câble HDMI : sous Windows, Win+P, puis « Dupliquer » ; sous Linux, Paramètres, Écrans, puis le mode miroir.
  • Sans fil : sous Windows, Win+K, puis choisissez la TV ; avec un Chromecast, dans Chrome, menu « Caster… », puis « Caster l'écran ».

Ceux qui suivent à distance voient la TV par la caméra de l'animateur.

Par Teams, dans le navigateur, sans installer l'appli

  1. Ouvrez le lien de la réunion, que l'animateur donne en salle, dans Chrome ou Edge, et choisissez de continuer dans ce navigateur.
  2. En salle, coupez le micro et le son de l'ordinateur avant d'entrer : sinon, effet Larsen.
  3. Pour montrer votre travail : le bouton Partager, puis la fenêtre du navigateur où tourne le site, ou celle de votre terminal, plutôt que tout l'écran. Sous Linux, autorisez le partage d'écran quand le système le demande.
  4. Arrêtez le partage à la fin de votre passage.
